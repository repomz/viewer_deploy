# Нагрузочные проверки Viewer

`http_load.py` выполняет только GET-запросы и не изменяет клинические данные.
Запускайте нагрузку ступенчато и контролируйте `docker stats`, число ошибок и
свободное место. Для локальной проверки HTTPS рабочего compose:

```bash
python3 http_load.py \
  --tls --insecure --host 127.0.0.1 --host-header 135.106.130.37 \
  --path /api/ --requests 500 --concurrency 10
```

Для проверки частичной выдачи MP4 добавьте `--range-bytes 262144` и укажите
путь подготовленной XA-серии. Не направляйте тест на команды агента, создание
отчётов, импорт или удаление исследований.
